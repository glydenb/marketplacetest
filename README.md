Marketplace desenvolvido com HTML, CSS e JavaScript

Funcionalidades:

--Cadastro de usuários
--Login e logout
--Recuperação de senha
--Sessão persistente no navegador
--Catálogo de produtos
--Busca por produtos
--Filtro por categoria
--Carrossel de produtos
--Seleção de vários produtos
--Controle de quantidade
--Carrinho persistente
--Alteração e remoção de itens
--Cálculo automático do total
--Finalização de pedido

Tecnologias:

--HTML5
--CSS3
--JavaScript
--LocalStorage

Se quiser vê-lo, siga estes passos:

1) Baixe ou clone o projeto
2) Abra a pasta no VS Code
3) Execute o index.html usando o Live Server
4) Acesse o site

Não é necessário instalar dependências

Observação:

A autenticação usa localStorage e serve para fins de estudo e prototipação. Para um ambiente de produção, o projeto precisa de um backend, banco de dados, hash de senhas e autenticação baseada em sessão ou tokens.
