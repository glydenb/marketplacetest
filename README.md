Marketplace desenvolvido com HTML, CSS e JavaScript

<h1>Funcionalidades:</h1>

<ul>
<li>Cadastro de usuários</li>
<li>Login e logout</li>
<li>Recuperação de senha</li>
<li>Sessão persistente no navegador</li>
<li>Catálogo de produtos</li>
<li>Busca por produtos</li>
<li>Filtro por categoria</li>
<li>Carrossel de produtos</li>
<li>Seleção de vários produtos</li>
<li>Controle de quantidade</li>
<li>Carrinho persistente</li>
<li>Alteração e remoção de itens</li>
<li>Cálculo automático do total</li>
<li>Finalização de pedido</li>
</ul>

<h2>Tecnologias:</h2>
<ul>
<li>HTML5</li>
<li>CSS3</li>
<li>JavaScript</li>
<li>LocalStorage</li>
  </ul>
<h2>Se quiser vê-lo, siga estes passos:</h2>

1) Baixe ou clone o projeto
2) Abra a pasta no VS Code
3) Execute o index.html usando o Live Server
4) Acesse o site

<h1>Não é necessário instalar dependências</h1>

<h1>Observação:</h1>

A autenticação usa localStorage e serve para fins de estudo e prototipação. Para um ambiente de produção, o projeto precisa de um backend, banco de dados, hash de senhas e autenticação baseada em sessão ou tokens.
